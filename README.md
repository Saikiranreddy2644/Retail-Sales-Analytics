# Retail Sales Analytics Project

## Project Overview
This project analyzes retail sales data using **SQL** for data modeling and **Power BI** for visualization.  
The goal is to derive business insights related to **sales performance, product performance, and customer churn**.

All transformations and aggregations were handled using SQL views, which were then imported into Power BI for dashboard creation.

---

## Tools Used
- SQL (MySQL)
- Power BI Desktop

---

## Data Modeling (SQL)
The following SQL views were created to support analysis:

### 1. Monthly Sales Overview
- Monthly revenue
- Total orders per month
- Based on delivered orders only

### 2. Product Performance
- Revenue and profit by:
  - Month
  - Product category
  - Product sub-category

### 3. Customer Lifetime Value
- Total revenue generated by each customer
- Calculated using delivered orders only

### 4. Order Status Funnel
- Count of orders by order status
- Used to understand order flow

### 5. Churned Customers
- Customers whose last delivered order date is more than **90 days** older than the latest delivered order date in the dataset
- Includes:
  - Customer ID
  - Last order date

All SQL files are organized inside the `/SQL` folder.

---

## Power BI Dashboards
The Power BI report consists of **three pages**:

### Page 1: Sales Overview
- Total Revenue
- Average Order Value
- Total Orders
- Active Customers
- Monthly Revenue Trend

### Page 2: Product Performance
- Top sub-categories by revenue
- Top sub-categories by profit
- Filters for:
  - Product category
  - Year-Month

### Page 3: Customer Churn Analysis
- Active vs Churned Customers (donut chart)
- Churn rate
- Churned customers trend over time

Screenshots of all dashboard pages are available in the `/Screenshots` folder.
